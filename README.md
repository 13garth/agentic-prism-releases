# Agentic Spark Releases

Agentic Spark is a free desktop workspace for building with AI. This repository contains public beta release downloads; application source is not published here.

Get the current downloads and installation guidance from [The Developer Market](https://thedevelopermarket.com/download) or [The Extension Market](https://theextensionmarket.com/download).

Public beta packages may be unsigned. Automatic updates are disabled. Follow the notes for your operating system in each release and compare its published SHA-256 with the downloaded file.

## Historical releases

The earlier **Agent Developer 1.0.0-test.13** Windows installer retains its original embedded name and filename. An installation problem has been reported and is being investigated; it is not the verified Agentic Spark replacement. Existing releases remain available as historical records.
